Introduction

Rust MCP sandbox for AI agents. Isolate Linux workspaces with nsjail and drive them from Claude Code or Cursor.

DAIMON exposes an MCP server whose tools line up with Claude Code's built-ins — Bash, Read, Write, Edit, Glob, Grep, WebFetch, plus a PTY session. Point an MCP client at a Linux host and the agent drives that machine's terminal as if the tools were local.

The kernel is a single Rust binary (static musl, amd64 / arm64). The same runtime is bundled in the sandbox-manager image and the macOS desktop app.

The wire is plain HTTP. There is no TLS. Do not expose the port on the public internet.

Quick start (Debian / Ubuntu)

Paste this into Claude Code (.mcp.json) or Cursor MCP settings, replacing the token. If you bound a Tailscale IP, put that host in url instead of 127.0.0.1.

Other clients, cluster, and desktop URLs: Connect. Other distros, Tailscale, upgrade: Linux binary.

Core MCP tools

ToolRole
BashRun a shell command; long jobs can move to the background.
Read / Write / EditRead, write, and patch files (text, images, PDF pages).
Glob / GrepFind files by pattern; search contents with ripgrep.
WebFetchFetch a URL through the sandbox instead of shell curl.
exec_command / write_stdinInteractive PTY session when you need a real TTY.
GetRuntimeContextWorkdir, filesystem/network policy, and tool capabilities.

Clients send X-Access-Token. /health is unauthenticated.

Tutorials

Linux binary

Static musl binary on any Linux. One-liner installer is Debian/Ubuntu + systemd. Put Tailscale in front — MCP is not encrypted.

Sandbox cluster

Scheduler in front, manager containers, nsjail sandboxes built inside each manager.

macOS app

Launch the desktop app, edit policy visually, run the kernel locally.

Connect

Claude Code, Cursor, or the SDK: URL + X-Access-Token.

Configuration

Environment file and sandbox-policy.yaml: host, token, paths, network.

Assets come from daimon-hq/release latest. A new core-v* or gui-v* tag updates what the install commands download.
